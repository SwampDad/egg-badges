# Egg Badges settings guide

Open **Options**, then choose **Egg Badges**. The screen does not pause the world.

## Layout

The screen has three groups:

1. **PERFECT EGGS (6x31)** - background choice.
2. **ICON** - Colored Circle filters or Show # of 31 IVs.
3. **OTHER** - Show Gender and Show Hidden Ability.

A preview in the upper-right reflects the current draft.

## Perfect eggs

The background applies only to perfect 6x31-IV eggs. Choose Forest Green, Slate Blue,
or Deep Purple. Use the Background checkbox to turn the fill off without losing the
chosen color.

## Icon

The Colored Circle uses Gold, Cyan, or White. Select one filter:

- **5x31** - exactly five IVs are 31. An optional `6th IV >` value preserves the
  threshold while the checkbox is off.
- **Custom IV Filter** - six stat rows with enable checkboxes, `<`/`>` operators, and
  thresholds from 0 to 31. Selecting Custom opens the editor. **Edit** collapses or
  expands it.

Selecting either filter activates the circle directly. Selecting the active filter
again clears it. With neither filter selected, no circle is drawn. Selecting a filter
turns off Show # Count, and selecting Count turns off the circle.

## Other indicators

- **Show Gender** adds a small upper-left corner marker.
- **Show Hidden Ability** adds an orange lower-right marker only when the egg's
  species, form, and ability are confirmed as hidden by local Cobblemon data.

Genderless and unknown eggs show no gender marker. Unknown Hidden Ability data shows no
marker.

## Save, Cancel, and Reset All

- **Save** is disabled until the draft differs from the saved settings.
- **Cancel** discards draft changes.
- **Reset All** returns the draft to the default settings; it does not persist until
  Save.

## Version label

The bottom-right footer shows `Egg Badges · v<installed version>` from Fabric metadata.
It remains outside the scrolling controls and above the action buttons.
